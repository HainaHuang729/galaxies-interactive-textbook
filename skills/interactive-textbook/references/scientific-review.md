# 来源、模型与独立核查

## 来源地图

记录书目、版本、章节/小节、印刷页、文件页、公式号、勘误、补充论文或数据版本。页码偏移可能分段变化，不套用其他书的常数。区分历史观测约束、当前研究补充和网页作者自行选定的教学参数。只陈述已取得并读到的材料；不从标题猜正文。

原书或讲义中的科学事实与方程可引用并解释；公开版本是否包含原文/图像，按其实际许可和授权判断。无再分发依据时保留原创讲解、可追溯引用和官方链接。

## 模型契约

为一个明确学习问题填写 `assets/templates/model-contract.json`，至少核对：

- 输入的物理含义、单位、范围、步长和默认值；范围的物理理由。
- 方程、常数、符号正负约定、参考零点、初值与边界条件。
- 密度是质量密度还是数密度；距离是角距离、物理距离还是共动距离；半径/直径、半宽/全宽、周期波数/弧度波数等区别。
- 积分量、当地量、微分率与有限时间变化的区别；归一化常数和积分域是否一致。
- 输出单位与变换链，例如秒/年、角秒/弧度、每频率/每波长、对数/线性数值。单位换算只在明确边界进行。
- 解析奇点的有限极限、零分母、无解和超出适用域的表示；不通过裁剪曲线或夹紧读数来掩盖物理错误。
- 近似的判据及读数：线性扰动、牛顿/相对论、稳态、等压、薄盘、有限源等是否在当前输入范围内成立。需要时收窄范围或明确切换模型。

计算函数返回完整精度的物理状态和有效性标志，绘图层据此派生数据；显示层才做舍入。随机模型需记录种子、样本大小和重新抽样条件；扫描检查位置不能悄悄重新抽样。

## 独立验证的方法

按模型选择有信息量的检查，不为每次低影响编辑建立整套新测试：

| 实现路径 | 可用的独立路径 |
| --- | --- |
| 包围质量、势或光份额解析式 | 按真实密度或面分布直接数值积分 |
| 解析时间响应 | 独立ODE积分与守恒/平衡账 |
| 投影或卷积 | 像面/速度域积分、矩或归一化不变量 |
| 随机抽样 | 解析分布矩、置信覆盖和固定种子统计 |
| 无量纲方程 | 在另一单位制下重算并换回 |
| 导数、增长率或临界点 | 有限差分、独立求根、两侧符号与连续性 |

不同语言本身不保证独立性；需要不同推导、算法或独立输入。独立夹具应有可复现脚本、常数来源、精度及误差说明，不导入待检模型直接生成“期望值”。若无法取得独立路径，说明验证限制，不能自行标为已独立核查。

覆盖全部输入的端点组合何时有意义由维度和物理风险决定；同时检查中心、边界附近、零点、换相/换近似、对称性和已知退化极限。不只检查“没有NaN”。例如质量/能量/光子预算、概率积分和包围份额须满足各自约束。

误差容限应来自单位、信号量级和数值方法。零点附近使用有量纲的绝对误差；极小但非零的信号要有相对误差或正值判据，避免 `max(1, |expected|)` 将它误吞。有限时间的一阶近似在瞬时导数零点处仍可能有非零二阶变化，不能保证统一的相对误差。

## 公式—曲线—读数的一致性

1. 在实际选定的参数下，比较模型输出、呈现数字和单位；读取机器保留的原值或结构化数据，不解析KaTeX的重复HTML/MathML `textContent` 作为数值。
2. 检查实际被绘制的节点，不只检查另存的一份理论数组。加入当前检查点和必要的边界/临界点，避免粗网格漏掉尖峰或零点。
3. 核对图面坐标映射与屏面投影、箭头方向与长度、动画时间及图例语义。非线性/对数轴要用对应的逆变换处理点击。
4. 固定参照、放大、缩放、切换量纲或重设参数后，再检查当前点、轴域与读数。不同物理量的参照不可无提示地混叠；固定参照若扩展图域，应明确反映。
5. 无临界点、在图域外和临界点恰为0分别显示，不把不存在的解挪到端点。按钮受控件步长影响时，区分解析位置与实际所选近似位置。
6. 重建生成文件后确认作者源仍能重现结果；只改生成HTML而被下次构建覆盖，不算完成。

输出复核记录的“适用范围”而不是绝对正确承诺。科学判断尚不确定时保留待查标签，并继续能独立完成的工作。
