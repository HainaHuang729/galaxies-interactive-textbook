# 从实测问题选择检查

以下是GALAXIES v36复核中发现的实现问题及可迁移的检查方法。具体模型、参数、章数和检查数量只是案例；其他书按自己的模型与风险选择检查。运行本技能无需取得该项目或原书。

| 发现的问题 | 下一本书采用的检查 |
| --- | --- |
| 公式写无限累计数量，代码却匹配有限、各自归一的累计份额 | 把积分变量、测度、上下限和分母逐项对照程序；以独立积分和反演检查内部点及端点。一般理论式与教学实现分别标注 |
| 读数精确，绘制折线却未经过当前物理点 | 读取实际路径的数据与几何，把当前点加入所属曲线；在非网格内部状态检查标记、探针和呈现数字 |
| 多曲线图的当前点需要明确所属的解、总数或所选轨迹 | 给曲线稳定身份，分别检查解/参照、分量/总和、被选轨迹；不要依赖默认第0条曲线 |
| 有限中心或波峰超出固定纵轴 | 比较所有绘制节点、当前点和固定参照与轴域；扩展、提供局部视图或明确裁剪，不截断数值。保留比较所需的共同尺度 |
| 低于阈值应为0，折线却跨过不连续点产生非零值；峰又取自粗网格 | 分别检查阈值两侧、阈值约定、驻点和约束边界；用分段表示与极值节点；零信号时不伪造唯一峰 |
| HTML ID或祖先章节抢占显式的中子/数密度等局部语境 | 在同一测试里提供显式语境、最近实验、祖先和通用候选；点击真实字形核对卡片。不能只测词典里是否存在这个字母 |
| D₊的+被当成加法，导数重音与基本量分离；Z_A变成ZA | 检查完整上下标与重音、定义和量纲；对易混完整量做实际点击回归。不要将所有含同字母的物理量合并为一个混合单位条目 |
| 复合指数被部分解析，页面无KaTeX错误却残留裸记号 | 将完整作者表达式与实际显示对照，检查动态说明和图内文本；扫描可见残留并排除隐藏副本，不能仅依靠解析器无报错 |
| 装饰性的原生选项预览被算成未绑定字形 | 记录实际可操作表面及装饰副本；只有已实测可聚焦的等价释义入口，才排除装饰层 |
| 仅跑主测试入口，遗漏早期模型或未被收录的已有检查 | 先清点模型、页面和测试脚本，按范围建立执行矩阵；核对独立ODE、解析极限或积分等证据确实对应待检实现 |

## 记录一次有效证据

记录模型/章节、参数和单位、曲线或字形ID、预期含义/结果、实际显示、验证方法、误差/容限与产物位置。独立计算说明与实现有何不同；UI证据说明命中了哪个对象。未运行的层级保留not-run，未知遗漏量保留null。

先完成本次范围，再报告检查矩阵中的已执行、未执行和排除项。无未绑定的数学字母，不等于所有术语及每个复合表达式已被穷尽式科学审查。表格中的方法是按问题选择的工具，不是要求每次文字修订重跑全部实验。

案例依据：[v36问题与方法](https://github.com/HainaHuang729/galaxies-interactive-textbook/blob/main/docs/whole-book-review-v36.md)、[实际覆盖记录](https://github.com/HainaHuang729/galaxies-interactive-textbook/blob/main/docs/whole-book-validation-v36.json)。这些链接供追溯实例，不是下一本书的物理基准或运行依赖。
