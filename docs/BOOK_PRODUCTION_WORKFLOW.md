# 从一本专业书到可验证的交互教材

这套流程来自GALAXIES的实际迭代：先做可核对的内容，再把交互、图像、符号解释和开源交付连成一条可重复的链。目标是读者能观察、操作、计算并解释结果。实验数量取决于物理问题，不设固定“五个”的上限。

## 1. 明确范围和来源边界

输入：书名、版本、作者、读者水平、语言、出版方式，以及合法取得的参考资料。原PDF设为只读，提取正文留在项目之外。公开仓库保存原创讲解与章节/页码/公式引用；有权限的开放教材可以按其许可使用。

先记录印刷页与PDF页的映射；偏移不是通用常数，本书的+22不能复制到下一本。检查版权页、目录、附录和作者勘误，建立逐章表：核心问题、概念、方程、先修关系、证据、适用近似、可操作参数、可验证极限。尚未读到或核实的内容标待查，不靠记忆填页码。

交付：`templates/book.config.example.json`、章节地图、来源登记表。原书、外部论文、官方观测与网页新增推导明确区分。

## 2. 先完成一个样板章

选择有明确因果关系和可独立验证模型的一章。每个教学单元依次回答：

1. 我们要解释什么现象？
2. 哪些量可测，哪些量是模型参数？
3. 方程为何成立，需要哪些假设？
4. 改变一个参数，哪条曲线或读数应怎样变化？
5. 哪个极限或反例会让本模型失效？

样板章必须包含连续叙事、来源、公式、图解、实验、符号解释和理解题，贯通阅读到验证。先在手机和两套主题上确认可用，再推广结构，不先铺16章空壳。

## 3. 建立“一个模型，多种表现”的契约

作者源模板：`templates/model-spec.example.json`。模型代码不读取DOM、不绘图、不把显示用的舍入值带回计算；返回有明确单位的结构化结果。曲线节点、探针、动画状态、读数、图例及伴读上下文从同一结果派生。

每个实验记录：输入域、默认值、单位、常数、方程、初边值、归一化、符号约定、输出、奇点处理、参考零点、不变量与失效条件。参数端点先由物理范围决定，禁止靠绘图裁剪掩盖负密度、超光速或发散。无解、不适用和数值0应有不同表示。

独立验证使用另一个推导或计算路径。例如：解析式对数值积分、守恒量对时间演化、独立Python高精度解对JS实现。复制实现写一份同样的代码不是独立证据。对接近0的量用绝对误差；对极小非零信号避免用误差容限把它吞成0。

## 4. 为每个图选择正确媒介

| 要解释的内容 | 优先方式 | 必须提供 |
| --- | --- | --- |
| 观测证据 | 官方观测产品 | 发布方、日期、处理方式、完整署名、许可 |
| 定量关系 | 程序生成的SVG/Canvas/标准绘图 | 坐标、单位、图例、色标、同模型数值 |
| 空间结构或因果过程 | 几何示意、交互装置或Anatomy | 示意范围、尺度与物理模型的对应关系 |
| 难以直接画出的直观场景 | 可选AI位图 | 科学审查、完整提示词、AI示意标识、非观测声明 |

不要用图片生成器制作精确数据点、光谱、带定量色标的场、公式文字或需要复核的曲线。Anatomy的实体必须支撑概念：几何审查、正确深度、真实接触与四层明暗；机柜或仪器若只是读出比喻应明说。生成图像本身不是科学依据。

## 5. 同步数学排版和上下文词典

长公式、行内变量、参数标签、轴标题、图例和动态读数统一使用同一数学渲染系统。中文与行内数学按基线对齐，检查上下标、重音、单位正体及细小字号。动态内容更新时立即格式化，避免先出现原始代码再闪动。

每个符号的词典键至少有“章节+实验”，必要时再加公式角色。`a`可能是尺度因子、长度或面积比；`E`可能是能量、统计期望或无量纲膨胀率。解释完整带下标的量，不能把σθ与σN都绑定到同一个泛化σ。模板见 `templates/symbol.example.json`。

释义包含名称、英文、定义、单位、成立条件、同字母区别和来源；缩写第一次出现应解释。既核对数据表，也点击浏览器里真正绘出的字形。无未绑定单字形不代表所有复合表达式已经逐条证明。

## 6. 让交互和动效承担教学任务

固定色彩语义、比例、坐标和读数布局。比较前后状态时说明纵轴是否自动缩放；如果归一化后图形形状不变，应另用绝对读数或固定参照刻度说明变化。不同物理量不要共用没有解释的纵轴。

动画推进模型时间或明确命名的扫描参数，不以装饰性旋转代替物理过程。保留暂停、手动步进、键盘、恢复默认和可复现参数。离开阅读页、隐藏标签页或图形不可见时暂停；减少动态效果模式保留静态探索。记录动画联系图，不能只看第一帧。

阅读结构采用适度分页、顶部左侧目录、清晰返回路径、图像大图和图表导出。桌面、390px和320px均检查轴标签、公式、按钮、触摸目标和横向溢出。

## 7. 逐章推进并记录复核

每一批新增内容都按同一顺序：来源查证 → 模型与独立基准 → 作者源与符号 → 图像/交互 → 数值回归 → 浏览器检查 → 复核记录 → 发布。完成一章也回看它依赖的公共排版、控件和模型接口。

优先修复科学与语义错误，再补学习路径和视觉细节。保留问题、原因、修正和证据，不把“通过测试”写成“所有科学结论绝对正确”。使用作者勘误时记录版本和具体公式号。原教材旧观测结果与新研究补充按年代分开。

本书可借鉴的例子：

- `docs/photometry-drift-science-v34.md`：Poisson误差传播、红移漂移与有限基线精度。
- `docs/shell-conduction-science-v33.md`：完整球壳势、热扩散的2π因子和等压极限。
- `docs/glossary-audit-v27.md`：同字母的公式语境和真实字形回归。
- `docs/reader-layout.md`：分页、来源与实验返回路径。

## 8. 面向所有人的交付

代码与原创内容的许可分别写清，第三方素材逐项登记；不把原教材声明成开源书。删除私人路径、部署身份、密钥、本地提取正文与用户状态。创建全新、已清理的公开源码快照，避免直接公开私人仓库历史。

交付源码ZIP、可直接运行的阅读ZIP、SHA256校验、启动器、README、贡献说明、科学纠错Issue模板与CI。先从最终ZIP解压，断网运行并操作实验，确认不是只有作者机器能运行。外部观测中有独立分发限制的素材保留官方链接，不塞进“自由素材”包。

## 下一本书的最小启动清单

复制 `templates/` 中四份JSON和提示词；填写真实书目信息与页码映射。第一批只交付章节地图和一个完整样板章。审核其来源、单位、参数域、独立测试、词典点击和手机排版后，再扩展全书。

现有GALAXIES仓库是可以参考和复用的实例，包含早期手写HTML和后期JSON作者源。它还不是只换配置就可出版任何书的通用系统。新书应建立自己的章节体系、模型、词典语境、独立基准和素材授权，不继承本书的数值参数与来源页码。

## 直接复用为技能

本流程已整理成 [`interactive-textbook`](../skills/interactive-textbook/SKILL.md)，并附科学核查、数学语义、图像交互与交付参考。整份技能可独立复制，运行时不依赖GALAXIES仓库或其原书PDF。

v0.2.0将本次复核的问题整理为[可迁移的检查案例](../skills/interactive-textbook/references/review-cases.md)，并在模型契约与复核模板中记录积分域、归一化、阈值/极值、实际路径证据和已执行的覆盖状态；下一本书使用同样标准，科学来源与具体模型重新核实。

调用示例：`$interactive-textbook 继续制作这本书的下一章，沿用现有风格，核对模型、图表、公式和局部符号解释。`

技能的可选 `scripts/init_book.py` 为新项目建立来源登记、章节地图、模型契约、符号与待运行复核记录；不会覆盖非空目录。已有教材直接在原项目上继续，不运行初始化器重建。
