## 1. 原书依据与新增推导的界限

- 第10章 §10.4.2，p.488：封闭箱、单区气体与恒星交换的起点。
- p.489，式(10.119)–(10.122)：瞬时回收率 `R`、净产额 `y_Z` 的定义与金属返还。`y_Z` 是每单位永久锁定质量中新合成并返回气体的金属量；不能误用每单位总形成质量的产额。
- p.489，式(10.123)–(10.124)：气体丰度 `Z_g = Z_0 − y_Z ln μ`，这里 `μ=M_g/M_0`，初始全为气体、封闭且总质量 `M_0` 不变。
- p.490，式(10.126)：恒星累计质量随出生金属丰度的表达式 `M_star(<Z)=M_0[1−exp(−(Z−Z_0)/y_Z)]`。
- **当前有限时刻的截断、除以当前锁定恒星质量的条件归一化、PDF、分位数与平均值是从上述方程新增推导的教学内容**。原书的式(10.126)不能被直接画成任意大 `Z` 下仍持续增加的“当前恒星样本CDF”。

## 2. 推荐实验范围

建议新实验名为“同一个封闭箱，恒星留下怎样的丰度分布”，放第10章 `chemistry`，紧随现有 `closed`，共用 `μ` 与 `y` 的物理定义。

最小参数集：

| 参数 | 建议范围 | 默认值 | 含义 |
|---|---:|---:|---|
| `mu` | 0.02–1 | 0.3 | 当前气体质量 / 初始气体质量 |
| `yield` | 0.005–0.03 | 0.02 | 每单位永久锁定质量的净产额 |
| `cut` | 0–0.12 | 0.01 | 点击／拖动的出生丰度阈值 `Z_cut`，质量分数 |

首版固定 `Z_0=0`，以便与现有 `closed` 完全一致。若未来增加预富集，单独提供 `Z_0`，全部公式须平移；不能只平移图轴而遗漏均值与金属预算。

这个范围内最大 `Z_g≈0.11736`，不涉及 `Z>1` 的质量分数矛盾。仍需注明恒定产额、瞬时回收、均匀混合的教学模型局限；如此高的丰度不意味着真实产额保持常数。

## 3. 可计算定义

令

\[
 u=1-\mu,\qquad L=-\ln\mu,\qquad Z_g=Z_0+yL,\qquad M_{\star,\mathrm{locked}}=uM_0.
\]

### 累计质量与当前样本CDF

设 `t=clamp((Z_cut−Z_0)/y,0,L)`。当 `0<μ<1`：

\[
 \frac{M_\star(<Z_{\rm cut})}{M_0}=1-e^{-t},\qquad
 F_\star(Z_{\rm cut})=\frac{1-e^{-t}}{1-\mu}.
\]

因此阈值低于 `Z_0` 时两者为0，阈值高于当前气体丰度 `Z_g` 时前者为 `u`、后者为1。不要把 `M_star/M_0` 和“当前恒星样本占比”混为同一读数。

### 当前锁定恒星的质量加权PDF

\[
 p_Z(Z)=\frac{1}{M_{\star,\mathrm{locked}}}\frac{dM_\star}{dZ}
       =\frac{e^{-(Z-Z_0)/y}}{y(1-\mu)},\quad Z_0\le Z\le Z_g,
\]

支持区外 `p_Z=0`；单位应写“每单位 `Z` 的归一化质量密度”，不能标成恒星数或 `M_sun`。

右端点的密度是单侧值，支持区外立即变为0。画直方图或填充时应保留截断边界，不将右端密度斜连到更高丰度处的零值。若以零值显示区外，加入同横坐标的边界节点或使用独立分段path。CDF则连续到1，可画右侧平台。

### 均值与分位数

\[
 \langle Z_\star\rangle=Z_0+y\left[1+\frac{\mu\ln\mu}{1-\mu}\right],
 \qquad
 Z_q=Z_0-y\ln\left[1-q(1-\mu)\right],\quad 0\le q\le1.
\]

`q=0.5` 给中位数。`0≤mean−Z_0≤Z_g−Z_0`，CDF在中位数处必须为0.5。

### 与现有 closed 的一致性

固定 `Z_0=0` 时，均值必须与 `AdvancedPhysics.evaluate('closed',{mu,yield}).values[1]` 相同，气体丰度与 `values[0]` 相同，锁定质量份额与 `values[2]/100` 相同。

在本模型的金属账户中：

\[
 \mu Z_g+(1-\mu)\langle Z_\star\rangle
 = Z_0+y(1-\mu).
\]

左边分别为气体与已锁定恒星所含的模型金属量除以 `M_0`；右边为初始金属量加净返回产额。此为单区瞬时回收账户，不是对恒星遗迹内部核合成全部重元素的另行测量。

## 4. 无样本端点与稳定实现

### `μ=1`

- 气体丰度 `Z_g=Z_0`，锁定恒星质量为0。
- 未归一化的累计恒星质量处处为0。
- 当前样本的CDF、PDF、均值、中位数及低丰度比例**未定义**。返回 `null` 或明确的无样本状态；读数显示“尚无锁定恒星样本”。
- 不显示 `0/0`、`NaN`、一个真实的δ峰或一条“0%的CDF”。`μ→1⁻` 的条件分布趋近 `Z_0`，这是极限，不是端点已经存在恒星。
- 参数动画若从1开始，第一帧先显示空状态，后续随着 `u>0` 显示分布。禁止为了动效凭空保留上一帧恒星样本。

### 稳定表达式

- `L = -Math.log(mu)`；近1也可用 `-Math.log1p(-(1-mu))`。若未来允许极小正 `mu`，不要仅使用后一式，因为 `1-mu` 可舍入成1。
- CDF分子用 `-Math.expm1(-t)`，不用 `1-Math.exp(-t)`。
- 分位数用 `Z0 - y*Math.log1p(-q*u)`。
- 当 `u<1e-4`，均值增量应使用

\[
 \frac{\langle Z_\star\rangle-Z_0}{y}
 =\frac u2+\frac{u^2}{6}+\frac{u^3}{12}+\frac{u^4}{20}+\cdots,
\]

一般项 `u^n/[n(n+1)]`；这与现有 `closed` 的前三项级数一致。不要把近1但不等于1的均值直接置零。

- 将归一化CDF的最终浮点结果限于 `[0,1]`，只防止约 `1e-15` 舍入误差，不能借此掩盖错误公式。
- 参数校验至少要求全部有限、`0<mu≤1`、`y>0`、`Z0≥0`。首版没有必要开放 `mu=0`：此理想模型的气体丰度发散，虽完整恒星样本的平均值趋向 `Z0+y`，不能将无限丰度当有限气体的实际读数。

稳定求值伪代码：

```js
const locked = 1 - mu;
const L = -Math.log(mu);
const gasZ = Z0 + y * L;
if (locked === 0) return { gasZ, locked, defined: false,
  massBelow: 0, cdf: null, mean: null, median: null };
const t = Math.max(0, Math.min(L, (cut - Z0) / y));
const massBelow = -Math.expm1(-t);
const cdf = Math.max(0, Math.min(1, massBelow / locked));
const meanRatio = locked < 1e-4
  ? locked/2 + locked**2/6 + locked**3/12 + locked**4/20
  : 1 + mu * Math.log(mu) / locked;
const mean = Z0 + y * meanRatio;
const median = Z0 - y * Math.log1p(-0.5 * locked);
```

## 5. 图表与交互规范

推荐显示两张共享线性丰度横轴的图：上图PDF填充和阈值下累计面积，下图CDF与阈值探针。CDF读数与填充面积来自同一 `cut`。均值、中位数、当前气体丰度分别用不同标记并标清含义，不能把 `Z_g` 当平均恒星丰度。

- 曲线显式采样 `Z_0`、`Z_g`、`cut`（在支持区内时）、均值与中位数；常规采样可在 `t∈[0,L]` 进行，再映射到 `Z=Z_0+yt`，避免窄分布漏采。
- 近 `mu=1` 时支持区很窄。自适应正横轴范围，或清楚声明是在放大支持区；不得把窄PDF拉宽后仍声称使用原坐标。
- 每个直方图柱的准确概率为 `[exp(-t_left)-exp(-t_right)]/u`，稳定写成 `exp(-t_left)*(-expm1(-(t_right-t_left)))/u`。柱高度如要表示密度，须再除以真实 `ΔZ`。
- 若增加对数丰度模式，必须用Jacobian：`dF/dlog10(Z)=ln(10)*Z*p_Z(Z)`。`Z=0` 不能放在有限对数坐标；不能只把线性PDF的横轴改成log。若使用 `[Z/H]`，必须额外指定 `Z_ref` 并注明它不是未经元素丰度／氢分数说明即可等同的 `[Fe/H]`。
- 当前分布是质量加权的锁定恒星出生丰度。不能直接称为观测G矮星数量分布；至少还需要固定IMF、寿命与选择函数等额外假设。若讨论G矮星问题，可链接第11章§11.8.2的独立观测主题，不将本实验构造直方图假称为数据。
- 建议读数：当前气体 `Z_g`、锁定恒星平均 `Z`、中位 `Z`、阈值以下的样本份额。账户检查可作为展开细节，展示气体金属、恒星金属、净产额三项。

## 6. 独立参考与预期值

`chemical-reference.json` 包含24组状态（`mu` 从1到0.02，`y`为0.005/0.02/0.03，包含极近1状态）。用256点 Gauss–Legendre 在两个独立变量中积分：

1. 按锁定质量坐标 `f=M_star/M0∈[0,u]`，出生丰度 `Z(f)=−y log1p(−f)`，直接积分得平均值。
2. 在 `t=(Z−Z0)/y` 上积分PDF，检查面积、CDF和均值。
3. 与当前 `closed` 的均值比较，并检查金属账户。

参考结果：PDF面积最大绝对误差 `2.89e-15`，两种变量积分的均值相对差 `5.85e-15`，金属账户相对差 `3.19e-15`，现有 `closed` 均值相对差 `1.37e-14`。

## 7. 第9–10章 HII／年轻星协配图的科学边界

### 可依据的原书位置

- 第9章§9.1.1，p.419：GMC与年轻星团的关联；不能把原书讨论的约千万年典型时标强制推广为所有分子云的精确寿命。
- 第9章§9.3.3，p.428：OB星的电离辐射、风和超新星反馈；光蒸发与云消散，反馈也可能触发局部形成，但并非所有亮边都必然触发成星。
- 第9章§9.4.2，p.433：大质量年轻星的光电离、吸积与群体环境；低质量原恒星盘／喷流示意与HII区不是同一种系统。
- 第10章§10.3.7，p.477式(10.89)：OB星UV电离与case-B复合平衡。p.478式(10.95)–(10.98)：在给定温度、密度与条件下的复合线光度。
- 第10章§10.3.8，p.483式(10.109)：Hα与SFR的特定IMF／丰度校准；图片亮度本身不是无需校准的SFR地图。

### 适合添加的两类图

**第9章：年轻星协与周围不规则电离气体的概念插图。** 少量很亮的蓝白大质量星、更多较暗的低质量星；周围有弥散电离气体、尘埃暗带和不规则中性云边缘。可有稀疏通道与遮挡，强调OB星的辐射与气体的关系。标题明确为“概念插图”，不标未计算的密度、半径、年龄或光子率。星协不必引力束缚，不能画成所有恒星都受同一稳定圆轨道控制；避免把所有成员画成相同质量、同样明亮的蓝星。

**第10章：恒星光与星云复合辐射的区别。** 一侧强调点状恒星连续光，另一侧强调同一区域中弥散的气体辐射；图上不生成伪光谱／仪器UI。可在网页另加准确图例说明Hα等线的来源，但不要把某一生成色直接解释为温度或化学丰度。不能由视觉颜色推出 `[Fe/H]`、精确年龄、SFR或净产额。

### 必须避免的视觉错误

1. **HII区不是必须空心的薄发光壳。** 现有 `stromgren` 模型假定固定均匀密度、内部电离；不能配一个完美空腔、所有发光物质只在薄边缘的图，却声称就是该均匀模型的实测密度。
2. 如要制作与模型定量对应的图，纯均匀、光学薄复合发射满足 `j_Halpha∝n_e n_p`，投影表面亮度随冲量半径 `b` 为 `I(b)∝2 sqrt(R²−b²)`。它是填充球的路径积分，中心更亮，而非天然边缘增亮环。真实壳层可呈边缘增亮，但需另一个壳层／动力学模型。
3. `stromgren` 的 `R(t)=Rs[1−exp(−t/trec)]^(1/3)` 是固定密度电离平衡建立模型。不要用同一动画把气体物质全部推成一堵壳，同时仍声称没有解流体膨胀。
4. 中性分子云冷、HII气体约 `10^4 K` 是不同组分；不要把所有尘埃或暗带也画成均匀炽热等离子体。HII意为电离氢，不是中性HI、H2或恒星风X射线高温泡的同义词。
5. Hα可作红色显示，但实际图通常多谱线、多波段与显示拉伸。若采用冰蓝／暖白统一美术色，只标显示色或概念配色，不宣称是望远镜直接记录的可见颜色或温度图。
6. 未指定年龄时，不在每个年轻星协周围强加同步超新星爆炸、整齐球壳与所有恒星同阶段演化。若选择非常年轻（例如几Myr以内）的概念场景，更应避免擅自添加大量超新星遗迹。
7. 避免将UV绘成真实可见的激光线、从一颗恒星向所有方向辐射的等粗发光棒；若用箭头，须在HTML图例中说明为光子方向示意。
8. 若绘制原恒星盘／双极喷流，喷流总体沿盘面法向；不将它误作来自每一颗普通OB星的大尺度HII喷流，或把盘和整个星协画成相同量级。
