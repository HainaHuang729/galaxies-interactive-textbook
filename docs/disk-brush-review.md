# 第 11 章：圆环质量联动

2026-10-18，本地更新；未推送或部署。

本批使用新安装的 `interaction` 技能及其 `references/brushing.md`、`references/linked-views.md`。目标是让读者比较等宽内外圆环的质量，将累计曲线上的区间映射到盘上对应圆环。使用 D3 brushX、一帧一次的联动绘制、程序移动事件保护、独立选区状态；窗口或章节重绘后重新读取坐标轴，忽略已被移除的拖拽层事件。其他新装技能未用于本批。

## 来源与模型

沿用 `content/chapter-11.json` 中指数盘的作者源、公式及既有 MBW (2010) pp.496–501 来源标注。本批未重新查阅原书，不新增原书页码、公式编号或观测结论。

设无量纲半径 x = R / Rd，累计质量份额 F(x) = 1 − (1 + x) exp(−x)。所选区间 [a,b] 的质量份额为 F(b) − F(a)，等价于对 x exp(−x) 从 a 到 b 积分。质量单位为太阳质量，物理半径单位为 kpc。分母是无限指数盘总质量，并非画幅内质量。累计曲线与新增读数共用 `AdvancedPhysics.diskEnclosed`，实现用 expm1 减少中心附近的相消误差。

输入区间来自当前图轴域；盘尺度与总质量继续使用原滑块及原输入范围。选区变化不重算或缩放坐标轴。盘尺度变化保持选定的无量纲区间，同时更新物理半径与场景圆环；总质量变化只改变绝对质量。原“检查半径”探针对应单一半径，与圆环区间分别显示。

场景保留原几何：盘投影纵横比为 0.5，水平半径 20 kpc 映射到原画布半径。SVG 圆环叠加在原 Canvas 上，不改变原粒子抽样。超出画幅时明确说明读数仍包含完整圆环。高亮不是动力学演化或观测数据。
