# 全书数学文字与配图复核

2026-10-16。此次检查覆盖16章的正文、公式、实验参数、读数标题、运行时说明、图例、SVG坐标与Canvas文字，以及来源/伴读对话框。原有118个公式块、333条显示公式的TeX源保持完整；新增共享行内TeX显示通路，不修改任何物理计算。

## 遗漏原因与修正

原有 `build-math.cjs` 仅处理 `.formula` 公式块。后8章虽都有 `formulaTex`，176个参数标签、189个读数名称与运行时曲线说明仍通过普通文本显示，导致MBH、Ts、τeff等符号没有上下标。

- 审定的显示词汇保存在 `content/math/inline-vocabulary.json`，支持显式 `\(...\)` 源。使用与显示公式相同的本地KaTeX版本输出HTML+MathML。
- 变量采用清晰的下标和希腊字母：例如 `M_{\rm BH}`、`L_{\rm Edd}`、`T_{\rm s}`、`x_{\rm HI}`、`\tau_{\rm eff}`；中性气体普查的 `ΣNHI` 正确排为求和 `\sum_iN_{{\rm HI},i}`。
- 全词边界保护NFW、IMF、MBW、作者姓名等普通文字；变量的含义仍由各实验定义。未把不同章节中的R、y、λ或代码参数tau混同为一个物理量。
- 正文与控件在首次显示和运行时更新后共用排版。原生下拉选择保留键盘/辅助技术操作，关闭状态使用TeX预览；不向原生option插入HTML。
- SVG保留数据路径，数学文字通过同一TeX字体显示；坐标留白按实际数学文字宽度计算，标签保持在视口内。Canvas数学注记在相同数据坐标上使用HTML文字层，画面仍由原有模型驱动。
- 限定旧组件的span样式，避免读数的块级排版或图例装饰误作用于KaTeX内部结构。
- 窄屏长式可横向滚动，必要时可聚焦并用方向键读取；图表探针与分页按键互不干扰。字体加载后会重新测量坐标留白。后8章切换主题或尺寸时只重绘正在阅读的实验，进入其他实验时再更新其图表，避免后台重复计算。
- 当前SVG导出保留数学排版，并嵌入KaTeX样式与WOFF2字库，导出的文件无需站点CSS或外部字体。放大与导出都使用当前参数。
