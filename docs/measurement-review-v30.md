# v30 · 分辨率、卷积与谱线读出

本轮深化第11和13章，新增两项独立、明确限制条件的观测教学实验；没有改变原书PDF，也未把教学装置称为真实观测仪器。

- 第11章 `beam-smearing-lab`：恒定亮度、线性视向速度梯度的一维局部模型。空间高斯PSF之后对观测坐标作矩形孔径提取，绘制完整高斯与均匀速度区间的卷积；与同二阶矩高斯及本征线型比较。标准差读数来自同一分布的二阶矩。梯度反号不改变对称积分线型；均值及平均速度梯度不因这个局部模型而被压平。零孔径是归一化极限，不虚构光子数。提供分辨率扫描、快照、参照曲线和伴读问题。
- 第13章 `line-spread-lab`：静止模板、恒星LOSVD、仪器LSF三项独立高斯卷积。模板未含仪器响应；固定速度等效宽度20 km/s，全部控件组合均保持物理模板通量非负。仪器分辨本领按FWHM定义。校准比例只影响反演，负方差显示无法反演，零方差显示边界。参数、曲线节点、扫描位置、读数及释义一致。
- Anatomy Figure：64个真实实体，固定双叶狭缝、导轨、支撑、螺钉、开放安装框和带边框探测面。图面上的缺额曲线读取同一模型；横向固定显示速度范围，纵向以当次峰值归一便于辨形，绝对深度以定量图及读数为准。移动的是读数墨迹，狭缝不随恒星速度宽度改变；未画虚构的光栅射线或声称完整光学设计。
- 两套主题使用共同色值；图例线型与实际曲线一致。公式使用自托管KaTeX，新增36条实验语境释义，并保留键盘、离页停止、减少动态效果支持。
