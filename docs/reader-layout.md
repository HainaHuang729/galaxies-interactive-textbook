# 分页阅读布局

采用两套可切换配色：「宇宙余辉」以石墨蓝与琥珀为主（背景 #10151c、面板 #1a222d、正文 #f1ece2）；「月白星图」以月白、靛蓝与紫色为主（背景 #edf0f7、面板 #fafbff、正文 #19263f）。顶栏右侧切换，localStorage 记住选择并同步同源标签页。宋体承担章节标题，系统黑体承担正文与控件，KaTeX 保留数学字形。

把空间让给每一页的物理问题：目录入口位于顶部左侧、品牌之前；章节封面、讲解、单个实验、公式与模型边界、单道理解题、来源分别成页。宽屏实验让图表位于左侧、参数位于右侧；手机沿原有顺序纵向阅读当前页，不缩小科学图表来硬塞屏幕。

```
顶栏：目录 / GALAXIES                  全书目录 / 上一章 / 伴读 / 配色
                         当前主题
                    图像与曲线        参数
                    读数与解释        公式入口
底栏：当前页标题                  上一页   页码 / 总页数   下一页
```

标题页、理论页与实验页按内容使用不同密度，宋体和仪器形态保持连续。分页使用已有的真实内容节点；不复制 canvas，不重建实验监听器，不更换数值模型。切换配色触发原位重绘，保留参数、当前页和焦点。旧章节与实验锚点、浏览器前后退、阅读位置、键盘范围输入和来源/伴读弹窗仍可使用。离页时暂停播放。无 JavaScript 时保留完整连续正文，打印时恢复全部页面。

手机与电脑的目录入口都放在顶部左侧，不遮挡当前页正文。宽屏双源仪器页把仪器和数值曲线并排放置。每个实验仍可在必要时纵向滚动，不压缩图像来凑固定高度。

精选实验的任务与核对值可展开查看，载入参数会调用原有输入事件并支持恢复。长页的继续查看入口位于底栏，避免悬浮遮住图表。公式页标明具体实验并可往返。独立说明页默认展开，概念组按单一主题分页；理解题作答保存在当前浏览器，可逐题清除。

构建：`node scripts/build-reader.cjs`；完整章节构建会在数学排版结束后自动加入共享阅读器。

部分章节的开篇加入原创 AI 科教插图。宽屏在标题与导语右侧显示完整图片，手机沿正文顺序显示；不裁切主体，不把文字嵌进像素，不对深浅模式做图片反色。图注说明主题与边界，另有观察线索。点击图片打开原生大图对话框，Escape 关闭并恢复触发按钮焦点；大图打开时阅读器方向键不翻页。图片仍归于原有封面，页码、实验锚点和参数保持不变。生成提示词、替代文本和素材清单由 `content/illustrations.json` 维护，构建末尾执行 `build-illustrations.cjs`。
