## 统一显示

沿用宇宙余辉与月白星图，图注采用 13px 正文节奏、11px 来源行、细边框与 8px 圆角；图解、图片及放大窗口的按钮统一。公式使用既有 KaTeX，面板统一背景、边线、内边距与水平滚动。图表保留数据、坐标与原有语义色，不给天文图像套主题滤镜。

正文图片是独立的阅读页，保留原有章节锚点，并新增稳定的 `illustration-*` 深链接。图片无裁剪；支持多图、原图放大、Esc 关闭和焦点返回。来源文字用 `data-no-math` 防止书目页码被自动数学解析。

修复共享 TeX CSS 构建器对 `span` 的全局替换：现在仅隔离 CSS 选择器中的元素名，避免把 `grid-row: 1 / span 6` 等合法布局值改坏。恢复封面、阅读器和旋转实验的跨行布局规则。
