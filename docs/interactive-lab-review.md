# 各章交互实验与数据图复核

2026-10-16，基于 16 章与独立旋转实验的现有源码、教材章节来源和参数定义。按公式、单位、归一化、控件端点、数值收敛及“画面是否表达当前模型”检查。共有 112 个章节交互单元与独立旋转实验；其中 105 个使用 `.lab` 容器，另外包括开篇图、时钟等交互。正文 32 组配图的专项复核另见 `figure-science-review.md`。

## 数据图与交互

章节 2–16 的常规坐标图使用统一的科学绘图框架：保持模型原始定义域及数据，自动计算轴留白、按定义域筛选对数刻度、弱网格、可换行轴标题、数据边界裁剪、统一线宽和图例。章节1保留原来的组分/时钟专用布局；独立旋转页保留已有精细曲线和半径探针，完成科学复核。

各章图表增加当前矢量图的放大和SVG导出。常规坐标图的指针/键盘探针明确读取坐标，不将鼠标插值冒充精确模型样本。实际模型取样仍由各实验的曲线和读数给出。放大和导出复制当前参数下的实际SVG，保留样式、裁剪与坐标；导出记录当前控件值。

视觉沿用宇宙余辉与月白星图两套主题，优先保障图表字号、单位、坐标范围、曲线区分和小屏阅读。已有锚点、参数持久化、重置、伴读问题、播放/暂停、离屏暂停和减弱动态继续保留。
