# 符号与术语释义

保持现有阅读器的宇宙余辉和月白星图主题。深色底 #10151c、纸面 #1a222d、正文 #f1ece2、辅助字 #b6b5b1、强调 #e5bf83、图线 #84bcd5；浅色完全使用既有主题变量。中文沿用 PingFang SC，解释标题沿用宋体，数学沿用本地 KaTeX。

正文中的可解释词采用细点下划线，公式中的字形可聚焦与点击。右侧原生对话框依次呈现本处符号、中文/英文名称、物理含义、单位、适用条件与教材依据。同字母的其他含义另列，不能自动混入当前解释。手机对话框使用全宽布局。读者也可按章节、中文、英文或符号查全书。

结构：`阅读页 → 点击词/符号 → 本处解释 → 同符号其他含义`，另有 `全书检索 → 章节筛选 → 条目`。只在读者操作后展示释义，无自动弹出，无新配色或装饰动画。

审阅：这是教材的随页注释，不增加仪表盘卡片，不打断分页和实验参数。物理定义来自维护的上下文数据；显示别名只用于识别，不推断变量含义。资料中的同字母冲突优先使用实验上下文，无法唯一确定时明确列出各处的含义，不能任意选一条。
