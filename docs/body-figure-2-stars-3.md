# 第2章赫罗图（body-figure-2-stars-3）

## 范围与模型

- 作者源：`content/body-figures.json` 中的 `body-figure-2-stars-3`。
- 渲染器：`dist/assets/body-figures-early.js` 的 `R['2-stars-3']`；交互接线在 `dist/assets/body-figures.js`，局部样式在 `dist/assets/body-figures.css`。
- 横轴为对数表面温度，范围 2,500–40,000 K，向右降低；纵轴为对数光度，范围 `10^-6`–`10^6 L/L☉`。
- 主序、巨星、白矮星三条带及全部散点都是确定性生成的合成教学点，共 170 个（100/40/30）。轨迹为主序幂律、巨星曲线和近似固定半径的白矮星序列，带半宽和散点离散度只用于显示类型范围；不是观测星表、恒星演化轨迹或数量统计。类型之间没有箭头。
- 点颜色按表面温度插值，仅为示意；所有圆点半径相同，不编码半径。

## 太阳与等半径虚线

- 太阳参照固定为 `T = 5772 K`、`L/L☉ = 1`（5772 K 采用 IAU 2015 B3 名义太阳有效温度）。
- 等半径虚线显示 `R = 0.01, 0.1, 1, 10, 100 R☉`，每一点都由黑体球面关系计算：
  `L/L☉ = (R/R☉)² (T/5772 K)⁴`。
- “同温对照”把温度固定在 3,500–10,000 K，并标出 `R = 0.01, 1, 30 R☉` 的模型光度。三项卡片、图内环标和读数由同一次计算产生。

## 交互与可达性

- 类型按钮（全部/主序/巨星/白矮星）用单一选择高亮一类，其余类型淡化；读出的点数与图内实际点数同源。
- 同温对照支持触摸、指针拖动和键盘方向键；滑动输入节点不会被局部重绘替换，避免中断拖动。
- “定位太阳”显示太阳参考十字线；“恢复默认”恢复全部类型、关闭对照和太阳定位，温度回到 5772 K。
- 图谱放大后仍保留同一组交互与状态；关闭时把状态同步回正文图。
- 星点不进入 Tab 顺序；操作入口都是原生按钮、复选框和滑块，图形有标题与动态读数状态。

浏览器检查实际验证：温度轴方向、太阳位置、按渲染路径反解的等半径关系、类型高亮读数、同温标记与卡片的同源数值、指针拖动、键盘操作、太阳定位/重置、放大打开与关闭、两种主题、1440/390/320 px 无整页或图形横向溢出，以及触摸点击。截图和报告写到系统临时目录 `galaxies-hr-figure-20261018/`。

## 限制

- 主序、巨星、白矮星带是为概念比较构造的教学参数化，不采用某个恒星演化库、金属丰度、年龄或初始质量函数，故不能据此拟合年龄或恒星族。
- 温度颜色是示意映射，不是黑体色度或仪器显示色；点的大小和数量都没有物理含义。
- 等半径关系只在球对称、黑体、有效温度近似下成立，不能用于有强临边昏暗、非球对称或未热化的天体。
